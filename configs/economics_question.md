

## Tier 1: Lookups and one-step values (depth 0–1)
| Metric | Formula |  |
|---|---|---|
| Line-item lookup | e.g., Revenue₂₀₂₄ |  |
| Absolute change | X_t − X_{t−1} |  |
| Gross profit | Revenue − COGS |  |
| Working capital | Current assets − Current liabilities |  |
| Net debt | Debt − Cash |  |
| Book value of equity | Total assets − Total liabilities |  |
| Market capitalization | Price × Shares |  |
| Free cash flow (simple) ✱ | Operating cash flow − CapEx |  |

## Tier 3: Growth, averages, time comparisons (depth 2–4)
| Metric | Formula |  |
|---|---|---|
| YoY growth | (X_t − X_{t−1}) / X_{t−1} |  |
| Max / min / average over years | e.g., max(Revenue 2021–2025) |  |
| CAGR ⚙ | (X_end / X_start)^(1/n) − 1 |  |
| ROA (average assets) | NI / ((TA_t + TA_{t−1}) / 2) |  |
| ROE (average equity) | NI / ((Eq_t + Eq_{t−1}) / 2) |  |
| Inventory turnover | COGS / average inventory |  |
| Receivables turnover | Revenue / average receivables |  |
| Change in working capital | WC_t − WC_{t−1} |  |
| Gross margin change (pp) | GM_t − GM_{t−1} |  |
| Revenue growth vs. cost growth | g(Revenue) − g(COGS) |  |

## Ways to add difficulty without new metrics
- **Cross-company:** "Which of A and B had the higher operating margin in 2024, and by how much?" adds +1–2 depth and an entity-tracking challenge.
- **Expand or collapse concepts:** the same metric at depth 1, 3 or 6 (named vs. expanded inputs). This is your knowledge-vs-composition comparison.
- **Peer ranking:** "Rank the 5 companies by ROIC" adds breadth.
